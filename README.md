# aiready-kit

My personal **rules and skills for AI coding agents**, with a terminal wizard to install them.

Works with [Claude Code](https://claude.com/claude-code) and any agent that reads `AGENTS.md` (Codex, Cursor, Copilot…).

## Install

Run this inside your project (needs Node.js 18+):

```bash
npx github:lucasviga/aiready-kit
```

```
┌  aiready-kit   skills & rules for AI coding agents
│
◆  What would you like to do?
│  ● Install skills / rules
│  ○ Show status
│  ○ Uninstall
│  ○ Create new skill / rule
│  ○ Exit
└
```

Pick what you want, then choose **This project** or **Global**. That's it.
